# phishing-awareness-guide
This a cybersecurity project that teachers users or people how to identify phishing attacks and protect their accounts and information
# PROJECT OBJECTIVES
Explain what phishing is.
Identify common signs of phishing attacks.
Teach users how to protect their accounts
Promote safe online behaviour.
# COMMON WARNING SIGNS
Suspicious links and email addresses 
Message that create urgency or fear
Request for passwords or personal information
Unexpected attachments.
Spelling and grammar mistakes.
# SAFETY TIPS
Avoid clicking suspicious links.
Enable multi factor authentication
Never share passwords or codes
Report suspicious messages to the appropriate Security team.
# LEARNING OUTCOMES
After using this guide, users should be able to recognise possible phishing attempts and apply basic measures to protect information
