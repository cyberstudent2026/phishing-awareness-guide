# CYBERSECURITY SAFETY CHECKLIST
This checklist provides simple steps that students and other users can follow to protect their devices, accounts and personal information.
# ACCOUNT SECURITY CHECKLIST
Use strong, unique passwords for each account.
Enable multi factor authentication where available.
Never share passwords or codes
Sign out of accounts on shared computers
Review account activity and report unfamiliar logins.
# EMAIL AND PHISHING PROTECTION
Check the senders email address before attempting to respond
Verify unexpected requests for money or sensitive information
Avoid clicking unknown links or attachments.
Report phishing messages to the appropriate security team
# DEVICE SECURITY
Install operating system and updates
Use reputable security software where appropriate
Lock unattended deviceS
Download software on;y from trusted sources
Backup important files 
# DATA PROTECTION
Do not upload passwords, personal records, or confidential information
Use approved encryption methods to protect data
Check file sharing permissions before sharing documents.
# CONCLUSION
Following the above basic practices help reduce common cybersecurity risks . Security requires regular attention, careful decisions and prompt reporting of suspicious activity.
